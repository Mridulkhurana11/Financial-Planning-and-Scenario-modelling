# Dataset files

Download the Walmart Recruiting - Store Sales Forecasting competition data from:
https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting/data

Place these four files in this directory:
- train.csv
- test.csv
- features.csv
- stores.csv

The files are not included in this repository template. Access is governed by Kaggle's competition rules. Do not redistribute the raw source files unless the applicable rules explicitly permit it.
